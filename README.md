# Surfer Bench

Surfer Bench is a benchmark project for evaluating new and existing large language models (LLMs).

## Getting started

With Git installed, run these commands in PowerShell to check out the project:

```powershell
git clone https://github.com/Seckcey/surfer-bench.git
Set-Location surfer-bench
```

The repository is ready for the initial benchmark specification. There are no runtime dependencies or benchmark commands yet.
